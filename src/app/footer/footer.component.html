Behind the project

Started as an Angular learning project during the COVID-19 pandemic, to give people a single place to check the situation at a glance.

Contribute

  1. Pick an open issue and ask to be assigned.
  2. Fork the repo and commit your changes.
  3. Open a pull request.

Data source

  • disease.sh — open disease data API
  • India totals via MoHFW, country data via Worldometers, history via JHU CSSE

This is not an official government website, and the data is not endorsed by any government body. Figures are collected from public sources for learning purposes and may differ from official records. Several sources stopped reporting after the pandemic, so the numbers shown are the last ones published.
